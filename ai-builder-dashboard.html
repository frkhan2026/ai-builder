High-significance items trigger a Slack DM to Faisal. Any teammate can run an on-demand briefing before a board meeting or KOL conversation. Conference notes added manually. Competitors: Penumbra/BSX, Inari/Stryker, Imperative Vascular, Inquis, AngioDynamics, Endovascular Engineering, Jupiter, Magneto, SonoVascular, Flow Medical, SurModics, Medtronic Liberant.

Sub-builds

Failure points & mitigations
Sub-build 2 — Weekly scanner (highest risk)
1
Publication site structure changes → silent zero results
Fix: If zero new entries written across all 6 publications, fire a Slack DM: "Scanner returned 0 results — manual check needed." Zero is never valid.
2
False positive competitor matches → junk in Notion
Fix: Require competitor name + at least one domain qualifier (thrombectomy, PE, pulmonary embolism, DVT, venous, catheter) to qualify a hit.
3
Significance misclassification → wrong priority acted on
Fix: For every High entry, include the article headline + one-sentence snippet in the Slack DM so Faisal can verify in 5 seconds.
4
Duplicate entries on retry or multi-publication story
Fix: Before writing, check Notion for an existing row with the same Source URL. Skip if found.
5
Notion writes but Slack fails (or vice versa)
Fix: Write Notion first, then Slack. If Slack fails, log a comment on the Notion entry. Notion is source of truth — Slack is notification only.
6
Scheduler silently stops firing
Fix: Every run writes a "Last scan" timestamp to a Notion metadata page. Every run ends with a Slack DM confirming count. Silence on Monday is the alert.
Sub-build 1 — Notion database
7
Competitor product name misses (highest-leverage fix)
Fix: Synonym dictionary — Penumbra → Lightning Bolt/Flash/CAVT/STORM-PE; Inari → FlowTriever/PEERLESS/Artix; Imperative → Symphony; E2 → Hēlo/ENGULF; Jupiter → SPIRARE.
8
Notion schema drift → silent malformed writes
Fix: Scanner validates all expected properties exist at start of each run. Missing property → log warning to Notion, skip write.
Sub-build 3 — /intel-brief
9
Stale data presented as current
Fix: Print "Last scan: [date]" as first line of every briefing. Flag prominently if last scan was more than 14 days ago.
10
Notion pagination miss → briefing silently incomplete
Fix: Explicitly paginate all Notion queries using next_cursor. Never assume the first page of results is complete.
Conference Intel Processing Scoped Medium

Takes a running Outlook draft and photos of handwritten notes accumulated throughout a cardiology conference like EuroPCR. Claude reads the handwriting directly via vision API, merges it with the Outlook draft in a single pass, and produces a polished, audience-segmented intel email with embedded action items — ready to send before landing. A second pass extracts action items and creates Notion follow-up tasks with function-level owners. Input: Outlook draft text + optional photos of handwritten notes. Output: one clean cross-functional email + Notion tasks.

Sub-builds
1 Draft Cleaner + Structured Summary 1–2 hrs
Paste raw Outlook draft + attach photos of handwritten notes → Claude transcribes handwriting (vision API), merges with draft, cleans prose, groups by theme (Clinical Feedback, Competitive Intel, Product Strategy, Regulatory, Action Items), tags each action item by function. Done when: structured document returned in under 5 min, reviewable before edits.
2 Audience-Segmented Email Generator 1–2 hrs
Takes structured summary → produces single polished email with clear sections per audience (Leadership, Sales, R&D, Regulatory, Clinical). Done when: draft copyable into Outlook and sendable as-is.
3 Follow-up Task Creator 2–3 hrs
Extracts action items from summary → writes Notion tasks with owner (by function) and due date 5 business days post-conference. Done when: tasks appear in Notion immediately after summary approval.

Failure points & mitigations
Sub-build 2 — Processing + CRM write (highest risk)
1
Wrong CRM row matched — writes to wrong site's data
Fix: Log matched row + top 2 runner-up candidates to output file every run. Colleen sees "Matched: Mount Sinai (confidence: high / runner-up: Montefiore)" and can catch a bad match before Monday.
2
Meeting Notes overwritten instead of prepended — data loss
Fix: Append-only logic. After writing, verify old content still exists in the cell. If missing, abort the upload and send Colleen the intended update as a text file.
3
Partial CRM write — CRM left in inconsistent state
Fix: Download → modify all fields in memory → upload once. If any step errors before upload, discard entirely and alert Colleen. Never write partial changes to the file.
4
Trigger fires but Claude fails silently — no outputs, Colleen unaware
Fix: Every Zoom AI email must produce a Slack DM to Colleen within 10 minutes ("Meeting processed ✓ — draft saved, CRM updated"). No DM = something failed.
5
Outlook draft with wrong or blank recipient — email reaches wrong person
Fix: Never guess an email address. If no contact extracted with confidence, create draft with [CONTACT NEEDED] in the To field. Colleen fills in before sending.
6
Zoom email format changes — section parsing breaks silently
Fix: Detect section headers case-insensitively ("recap", "next steps", "summary"). If none found, abort and forward the raw email to Colleen with a note that processing failed.
7
Concurrent CRM edit / SharePoint file lock — write fails or corrupts
Fix: Check for file lock before writing. Retry ×2 at 2-minute intervals. If still locked on third attempt, write all outputs to text file and alert Colleen.
8
Multi-site meeting — Claude writes to one site, misses the other
Fix: If 2+ site names detected in summary, flag for manual update. Output CRM fields for all detected sites to text file. Do not attempt any automated write.
9
Duplicate trigger — two Outlook drafts sent to same contact
Fix: Extract Zoom meeting ID from the email. If same ID processed in last 24 hours, skip and log. Do not re-process.
10
Non-site meeting slips past the behavioral gate
Fix: CRM name match is the automatic backstop (Option C). Low-confidence match = skip silently, log to skipped-meetings.txt. High confidence required to proceed. No alert to Colleen.
